Each cluster is a course: a sequence of sessions that build on each other, from the internals up to real production scenarios.

## How a session is structured

1. **Concepts**: one idea at a time, from the physical storage layer upward.
2. **Lab**: predict the result, run it, compare with the prediction.
3. **Real-world scenario**: where the concept shows up in production and how to measure it.
4. **Check questions**: what you should be able to answer before moving on.

The first course is **Indexing**, in eight sessions covering PostgreSQL, MySQL and MongoDB.
