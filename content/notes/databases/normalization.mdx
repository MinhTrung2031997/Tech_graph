- **Normalization in SQL** is the process of organizing data in a relational database to **reduce redundancy**, **remove anomalies**, and **ensure data integrity**.
- Think of normalization as a set of rules that help you design **clean, efficient, consistent database schemas**.

<Divided>

## What it is

What is normalization?

Normalization ensures:

✔ No duplicated data

✔ No unnecessary dependencies

✔ No update anomalies

✔ Consistent structure

✔ Efficient storage

It breaks a large, unorganized table into **smaller, well-structured tables** connected by **foreign keys**.

## Why

Why we need normalization? Problems it solves.

### Update anomaly

Same data stored in multiple places must be updated everywhere.

### Insertion anomaly

You cannot insert data because another field is missing.

### Deletion anomaly

Deleting one row removes valuable related data unintentionally.

Example:

If you delete a student's course row → the student disappears entirely.

Normalization eliminates these issues.
