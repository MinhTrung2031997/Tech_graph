TanStack is a collection of open-source libraries for building modern web applications with frameworks such as React, Vue, and others. It provides solutions for data fetching, routing, tables, forms, and server-side rendering.

## What is TanStack used for?

- Data fetching and caching: Manage API requests, caching, background refetching, and server state.
- Routing: Handle navigation, nested routes, URL parameters, and data loading.
- Table management: Build tables with sorting, filtering, pagination, and row selection.
- Full-stack React applications: Support server-side rendering (SSR), server functions, and data loading.

## Advantages of TanStack Query

- Caching: Stores previously fetched data to reduce unnecessary API requests.
- Automatic refetching: Refetches data when configured conditions are met, such as when the window regains focus.
- Loading and error states: Provides built-in states to handle loading, success, and errors.
- Background refetching: Refreshes stale data in the background while keeping cached data available
- Automatic retries: Retries failed queries according to the configured retry policy.
- Pagination and infinite queries: Supports paginated data and loading more data incrementally.
- Cache invalidation: Allows related queries to be marked stale and refetched after mutations
