<ArticleStack>

- Ory is a modular Identity and Access Management (IAM) platform that helps applications manage user identities, authentication, authorization, and access control.

<Divided>

## Used for

What is Ory used for?

- Authentication: Verify who the user is.
- Identity management: Handle registration, login, password recovery, and user sessions.
- OAuth 2.0 / OpenID Connect (OIDC): Enable secure token issuance and delegated access.
- Authorization: Determine what resources and actions a user is allowed to access.

## Main components

- Ory Kratos: Identity management, login, registration, MFA, sessions
- Ory Hydra: OAuth 2.0 and OIDC; issues access tokens and ID tokens
- Ory Keto: Fine-grained authorization and permission checks
- Ory Oathkeeper: Identity-aware proxy that authenticates and authorizes incoming requests
