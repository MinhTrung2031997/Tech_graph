## 4 Characteristics of Object-Oriented Programming

### Encapsulation

Encapsulation hides the internal processing properties of an object to ensure data integrity. Other objects cannot directly change the object's state and can only interact through its public methods.

### Inheritance

Allows objects to inherit properties and methods from other objects, eliminating duplicate code in a system

### Polymorphism /ˌpɑː.liˈmɔːr.fɪ.zəm/:

<u>The same method name can perform different actions based on context.</u>

There are two main types:

- **Override:** Redefining a method in a child class
- **Overload:** Having multiple methods with the same name but different parameters within a class.

### Abstraction

Abstraction is the process of hiding implementation details while exposing only essential features to the user. It reduces complexity by showing only the necessary properties and methods of an object.
