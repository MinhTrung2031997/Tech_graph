## Reducing code with Arrow Function

- The syntax ES6 is briefer than ES5
- We don’t have to use the **function** keyword, even if The simple function doesn’t have to handle much, you don’t have to use the **return** keyword.

## Manipulating (/məˈnɪpjuleɪt/) objects in ES6 vs ES5

Things like object **destructuring** and **rest/spread operators** made it working with objects very easy

</Divided>
  <SplitPair>
    <SplitLead>destructuring</SplitLead>
    <SplitCol title="ES5">

If you have to extract multiple values from ES5 you have to write 3–4 lines of code

```text
var obj1 = { a: 1, b: 2, c: 3, d: 4 }
var a = obj1.a
var b = obj1.b
var c = obj1.c
var d = obj1.d
```

</SplitCol>
    <SplitCol title="ES6">

```text
const obj1 = { a: 1, b: 2, c: 3, d: 4 }
const { a, b, c, d } = obj1
```

</SplitCol>
  </SplitPair>

**rest**: Gather the remaining values into an array - Reference

**spread**:

- Copy and update and object

## Promises vs Callbacks

- The ES6 Promises allows us to `resolve` and `reject` a request. Whenever we resolve a request, it will call the callback provided in `then` and whenever we reject a request it will call the `catch` callback.
- The ES6 promise is better than callback because it allows us to distinguish easily between `success` and `error` so we don’t have to check again for things in callback function.

</Divided>

## Exporting & Importing Modules

Export

</SplitLead>
    <SplitCol title="ES5">

```javascript
module.exports = myModule;
```

</SplitCol>
    <SplitCol title="ES6">

```javascript
export default myModule;
```

- The ES6 syntax is more readable than ES5
- Comes up with `export default` keyword

</SplitCol>
  </SplitPair>
  <SplitPair>
    <SplitLead>Import</SplitLead>
    <SplitCol title="ES5">

```javascript
var myModule = require('./myModule');
```

</SplitCol>
    <SplitCol title="ES6 version">

```javascript
import myModule from './myModule';
```

With the ES6 version When you export something using `export default` keyword we will import a module with **import** keyword

</SplitCol>
  </SplitPair>
  <SplitPair>
    <SplitLead>

ES6 also provides us with the ability to `export` and `import` multiple child modules or variables from a single module

</SplitLead>
    <SplitCol title="export">

```javascript
export const x = 1;
export const y = 2;
export const z = 'String';
```

</SplitCol>
    <SplitCol title="import">

```javascript
import {x, y, z} from './myModule';
```
