  <Divided>

- Hoisting is a JavaScript mechanism where variable and function declarations are processed before the code is executed.
- In simple terms, JavaScript behaves as if certain declarations are moved to the top of their scope, although the code itself is not physically moved.
- You can call the function before its declaration because function declarations are hoisted with their function definition available.

</Divided>
  <Divided>

## Key takeaway:

- `var`: Hoisted and initialized with `undefined`.
- `let` / `const`: Hoisted but inaccessible before initialization (TDZ).
- `function declaration`: Hoisted with the function definition available.

</Divided>
